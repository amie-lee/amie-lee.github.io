## 사전 준비

시작에 앞서, 오픈클로는 내 컴퓨터에서 동작하면서 인간의 작업을 대신해주는 녀석입니다. 그렇기 때문에 나의 수많은 정보가 담긴 기존 계정을 사용하기엔 조금 꺼림칙한 부분이 있어서 애플과 구글 계정을 둘 다 새로 만들어주고 시작했습니다.

오픈클로는 오픈소스로, 터미널에서 간단하게 설치할 수 있습니다. 다만, 몇 가지 항목이 준비되어 있는지 확인하고 없다면 먼저 설치해주셔야 합니다!

``` sh
# Git 확인
git --version
# 없으면 설치 팝업이 뜹니다! 혹은 xcode-select --install 로 설치

# Homebrew 확인
brew --version
# 없으면 설치
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Node.js 확인
node --version
npm --version
# 없으면 설치
brew install node
```

## 초기 설정

설치가 완료됐다면 아래 명령어를 실행해주세요.

``` sh
openclaw onboard
```

![](/assets/img/posts/2026-02-23/img2.png){: .w-75 .normal}

## 텔레그램 봇 세팅

웹 대시보드로만 채팅할 순 없으니 이제 텔레그램 봇을 연결해야 합니다.

앞서 토큰을 발급했을때 BotFather가 보내준 내 봇 링크를 클릭하거나 검색창에 내가 만들었던 username으로 검색해 나의 봇을 찾아줍시다.

내 봇에게 `/start` 를 보내면 아직 설정되었다지 않았다는 말과 함께 페어링 코드를 보여줍니다.

이제 터미널로 돌아갑니다.

``` sh
# 위에서 확인한 페어링 코드가 동일하게 표시됩니다
openclaw pairing list telegram

# 확인한 코드와 함께 입력합니다
openclaw paigin approve [페어링코드]
```

다시 봇에게 `/start` 를 보내보면 이렇게 답이 옵니다!
