#### 1. Github Actions
다른 블로그에서는 빌드&배포를 Deploy from a branch로 설정해도 정상적으로 테마 적용이 되던데, 내가 사용한 Chirpy는 Github Actions로 빌드해야 하는 테마였다.

Github Actions로 Repository Pages 설정을 바꿔준다.

![빌드&배포 세팅 변경](/assets/img/posts/2026-01-29/img2.png){: width="972" height="589" .w-75 .normal}

Github Actions로 빌드하기 위해서는 `.github/workflows/pages-deply.yml` 파일이 필요하다. 파일 생성은 클로드 코드에게 맡겼다.

``` yml
name: "Build and Deploy"
on:
  push:
    branches:
      - main
      - master
    paths-ignore:
      - .gitignore
      - README.md
      - LICENSE

  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup Ruby
        uses: ruby/setup-ruby@v1
        with:
          ruby-version: 3.3
          bundler-cache: true

      - name: Setup Pages
        id: pages
        uses: actions/configure-pages@v4

      - name: Build site
        run: bundle exec jekyll build -d "_site${{ steps.pages.outputs.base_path }}"
        env:
          JEKYLL_ENV: production

      - name: Upload site artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: "_site${{ steps.pages.outputs.base_path }}"

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4

```

그러면 이제 빌드가 잘 되어야 하는데...

#### 2. Starter 템플릿의 존재

여전히 빌드 오류가 발생해서 클로드에게 물어보니 Chirpy 테마는 직접 복사하는 대신 Chirpy Starter 템플릿을 사용하는 것이 권장된다고 한다.

나는 너무 많이 와버렸기 때문에 클로드의 조언대로 Gemfile을 수정하고 불필요한 파일을 정리하니 해결되긴 했다.

그런데 이제와서 Getting Started 페이지를 확인해보니 레포 생성부터 배포까지 가이드가 적혀 있었다.

친절하게도 처음부터 복제해서 레포로 만들 수 있는 템플릿을 제공하는 테마였는데, 레포부터 만들고 따라하다보니 이 부분을 놓쳤다.
